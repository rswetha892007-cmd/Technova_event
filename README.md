TECHNOVA 2026 – Event Landing Page

About the Project

TECHNOVA 2026 is a responsive landing page for a college technical event. It presents event information in a modern and user-friendly layout.

Features

- Event title and banner
- Event date, time, and venue
- Event highlights and schedule
- Registration button
- Responsive layout for desktop, tablet, and mobile
- CSS Flexbox and media queries
- Hover effects and smooth scrolling

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

Project Structure

- "index.html" – Website structure and content
- "style.css" – Styling and responsive design
- "screenshots/" – Desktop and mobile screenshots

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Resize the browser to test the responsive layout.
